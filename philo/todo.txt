while (philosopher_is_alive && not_finished_eating) {
    think();
    take_forks();   // Prend la fourchette gauche puis droite (attention à l'ordre !)
    eat();
    put_down_forks();
    sleep();
}

🔄 Détail des fonctions

think()
    Le philosophe "pense", il ne fait rien pendant un certain temps.
    Ce temps peut être court ou nul si tu veux optimiser.

take_forks()
    C’est ici que tu dois protéger l’accès concurrent aux fourchettes.
    Tu utilises des mutex (ou des sémaphores selon la version) pour verrouiller les deux fourchettes nécessaires.
    Astuce pour éviter les deadlocks : ne pas toujours prendre les fourchettes dans le même ordre pour tous les philosophes.

eat()
    Une fois les deux fourchettes prises, le philosophe mange pendant time_to_eat ms.
    Il faut ici mettre à jour le timestamp de son dernier repas pour éviter qu’il soit considéré comme mort.
    Tu peux aussi incrémenter un compteur de repas.

put_down_forks()
    Le philosophe relâche les deux fourchettes (mutex unlock).
    Important de bien libérer dans tous les cas pour ne pas bloquer les autres.

sleep()
    Le philosophe dort pendant time_to_sleep ms.
    C’est une simple pause, mais elle peut aussi être interrompue si un philosophe meurt.
